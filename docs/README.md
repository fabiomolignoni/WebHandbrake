## How these documents stay correct

- **Generated, not copied.** [user-guide.md](user-guide.md), [traceability.md](traceability.md)
  and the [ADR index](adr/README.md) are generated by `npm run docs` from the code, the tests and
  the ADRs; edit their sources, not the files.
- **Facts are checked.** A value that comes from code, such as a minimum browser version or a
  limit, is written between `<!-- fact: name -->` and `<!-- /fact -->`, and the check compares it
  with the code.
- **One source for each topic.** Other documents link to it instead of repeating it.
- **Checked in CI.** `npm run docs:check`, part of `npm run check`, fails on a stale generated
  file or fact, a broken link or anchor, a missing file or npm script, an undefined or untested
  requirement ID, a malformed ADR or changelog, an undocumented environment variable, a permission
  missing from the privacy policy, or a word the glossary avoids in user-facing text. Each check
  is described at the top of its file in `scripts/docs/checks/`.
- **External links** are checked every week by `.github/workflows/docs-weekly.yml`.
