# ADR 0005 — Internationalisation with ICU messages

- Status: accepted
- Requirements: I18N-01…I18N-04, SET-02

## Context

`browser.i18n` cannot switch language independently of the browser and has no plural rules.

## Decision

Application strings live in `src/locales/<lang>.json` using the WebExtension JSON layout
(`message` + `description` for translators), with ICU MessageFormat syntax for plurals and
selects, formatted by a small in-house formatter based on `Intl.PluralRules`. English is bundled;
other languages are loaded on demand and fall back to English key by key. Only manifest strings
use `_locales`. A CI script checks that every key used in the code exists.

## Consequences

Compatible with Weblate/Crowdin, language selectable in the settings, right-to-left ready
(document direction set from the locale, logical CSS properties).
