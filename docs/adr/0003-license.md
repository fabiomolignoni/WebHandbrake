# ADR 0003 — GPL-3.0-or-later

- Status: accepted
- Requirements: D1, MAINT-04

## Decision

WebHandbrake is licensed under the GNU General Public License v3.0 or later, so that forks remain
open and auditable — important for an extension that needs access to all sites. Code is a rewrite;
LeechBlock NG (MPL-2.0) was only consulted for the format of its exports.
